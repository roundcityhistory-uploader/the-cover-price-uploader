Privacy Policy

The Cover Price Uploader · last updated 3 September 2026

This policy describes how The Cover Price Uploader (“the application”) accesses, uses, stores and shares Google user data.

The application is a private tool with exactly one user: the owner of the YouTube channel it publishes to. It is not distributed, not offered to the public, and has no facility for any other person to sign in.

1. What data the application accesses

The application accesses only the Google account data of the channel owner, and only through the YouTube Data API, using these scopes:

ScopeWhy it is needed
youtube.upload To upload the owner's own finished video files to the owner's own channel.
youtube.readonly To confirm the correct channel is being written to, and to read back an upload's own title, privacy setting and scheduled publish time to verify it was recorded as intended.
youtube.force-ssl To attach caption tracks and to set the AI-content disclosure that YouTube's policy requires. These are write operations the upload scope alone does not permit.

The application does not request, and cannot access, Gmail, Drive, Contacts, Calendar, Photos, location, or any Google service other than YouTube.

2. What it does with that data

The data is used solely to publish the owner's own videos to the owner's own channel: creating the video entry, setting its metadata, attaching captions, declaring AI use, and reading the result back to confirm it is correct.

It is not used for advertising, profiling, training machine-learning models, or any purpose unrelated to publishing those videos.

3. What is stored, and where

The application stores an OAuth refresh token in a file on the owner's own computer, outside any synced or shared folder. That token is what lets it upload without the owner signing in every time.

No Google user data is stored on any server, database or third-party service. There is no backend. Video files, captions and metadata are the owner's own files on the owner's own machine.

4. What is shared

Nothing. No Google user data is sold, rented, transferred, or disclosed to any third party. The only party the application transmits data to is Google itself, in the course of uploading to YouTube.

Published videos are of course visible on YouTube once released, under the channel's own settings — that is the point of the application, and is governed by YouTube's Terms of Service and Google's Privacy Policy.

5. Retention and deletion

The refresh token is kept only as long as the owner uses the application. Deleting the token file removes it immediately and completely.

Access can be revoked at any time from Google Account › Third-party apps & services, which invalidates the stored token straight away.

6. Limited Use

The application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

7. Children

The application has a single adult user and is not directed at children.
